Park English đã lên web

Game 3D chạy bằng Next.js + React Three Fiber và server Colyseus. Toàn bộ mã đã được merge vào nhánh chính trên GitHub (7 PR). Site Vercel báo "Failed to fetch" vì server game chưa được deploy: xem phần dưới.

Việc còn lại: deploy server game

Site lov-eng.vercel.app gọi http://localhost:2567 (địa chỉ mặc định) nên trình duyệt tìm server trên chính máy người dùng và báo "Failed to fetch". Vercel không chạy được Colyseus vì cần WebSocket liên tục.

  1. Deploy server lên nơi chạy container có WebSocket (Fly.io, Railway, Render...). Đã có Dockerfile ở gốc repo và hướng dẫn trong docs/DEPLOY.md.
  2. Trên Vercel đặt biến NEXT_PUBLIC_GAME_SERVER_URL=wss://địa-chỉ-server rồi redeploy (giá trị được nhúng lúc build).

Mình chưa deploy giúp vì cần tài khoản hosting của bạn. Từ giờ client hiện thông báo rõ ràng thay cho "Failed to fetch" khi thiếu cấu hình.

Trong trình duyệt thật: vào game bằng form, đảo và nhân vật hiện đúng, console không lỗi. Đi bộ bị chặn bởi đài phun nước (va chạm hoạt động). Đứng gần Sam bấm E mở nhiệm vụ. Câu sai bị từ chối, câu đúng qua lượt, xong nhiệm vụ nhận 7 XP và mở Coffee Shop, tiến độ lưu ở server.

Mở 2 cửa sổ trình duyệt cùng lúc: thấy "2 online", chat gửi từ cửa sổ này hiện ở cửa sổ kia. Joystick ảo đưa nhân vật đi 6,4 m về phía bắc trên màn hình điện thoại giả lập. Smoke test 2 client: thấy nhau, di chuyển đổi vị trí, chat gần được lọc từ tục, nhiệm vụ bị từ chối khi ở xa NPC, người dưới 18 tuổi bị từ chối khi vào.

Chưa kiểm tra hoặc còn thiếu

  • Micro thật chưa thử. Khung trình duyệt chặn micro. Đường nói dùng Web Speech API của trình duyệt; đường gõ thay thế đã chạy.
  • Chưa thử trên điện thoại thật và chưa đo FPS. Joystick mới thử trên màn hình giả lập.
  • Server game chưa được deploy nên bản Vercel chưa chơi được.
