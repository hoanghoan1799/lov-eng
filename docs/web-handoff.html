Park English đã lên web

Game 3D chạy thật bằng Next.js + React Three Fiber và server Colyseus. Mã đã chia thành 5 nhánh xếp chồng trong repo local, nhưng chưa push được lên GitHub vì máy đang đăng nhập sai tài khoản.

Việc bạn cần làm: push

Lệnh push bị GitHub từ chối: Permission to hoanghoan1799/lov-eng.git denied to hoanhoang-agilityio. Máy đang lưu thông tin đăng nhập của tài khoản khác. Mình không thử khoá hay token nào khác. Hook của repo cũng chặn push thẳng lên main, nên chỉ có nhánh tính năng.

cd /Applications/Self-Project/l-eng
# đăng nhập đúng tài khoản hoanghoan1799 (token hoặc SSH key của tài khoản đó), rồi:
git push -u origin chore/monorepo-shared-content feat/blender-tools feat/game-server \
  feat/web-island-multiplayer feat/web-missions-chat

Repo đích đang trống, nên GitHub sẽ lấy nhánh đầu tiên làm nhánh mặc định. Nếu muốn có main trước, hãy tạo nó trên GitHub (ví dụ thêm README), rồi mở 5 PR theo thứ tự, mỗi PR nhắm vào nhánh đứng trước nó. Mình không có công cụ gh để mở PR thay bạn.

Chưa kiểm tra hoặc còn thiếu

  • Không có điều khiển cảm ứng. Trên điện thoại chưa đi được (chỉ có WASD/mũi tên). Cần joystick ảo.
  • Micro thật chưa thử. Khung trình duyệt chặn micro. Đường nói dùng Web Speech API của trình duyệt; đường gõ thay thế đã chạy.
  • Chưa mở 2 cửa sổ trình duyệt cùng lúc. Nhiều người chơi chỉ được kiểm chứng bằng client SDK trong smoke test.
  • Chưa đo FPS trên máy thật. Camera chưa né vật cản (có thể xuyên qua đài phun nước hoặc cây).
  • Chỉ 4 nhiệm vụ đã viết (Park, Coffee, Restaurant, Supermarket). 6 điểm còn lại báo "chưa có nhiệm vụ".
